# AetherConsole 2 · 送审摘要(给老板的快速审阅页)

> 完整规格见 [spec.md](spec.md)(v0.2)。**规格批准(= M0)通过前不写任何实现代码。**

## 一、为什么重制(AC1 的问题)

AC1 成品更像"一套渲染库",而不是"一台游戏机":分辨率 240×180 不能被 8 整除、颜色三种模式并存、游戏代码主线程裸跑、卡带不设上限、工具链缺代码编辑器和调试设备。AC2 按您的需求把规格全部收紧定死,并补齐官方工具链(代码编辑器暂缓,T16)。
