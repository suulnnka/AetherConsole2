AetherConsole 2 · 工具链

七件可用,代码编辑器暂缓(T16) ← 主机

打包环境

文件夹即项目:拖入游戏文件夹一键出品 .aec(标准/混淆),预算面板 + 装载冒烟。

图像编辑器

三模式:精灵绘制(8/16)、地图绘制(8px 网格 + 碰撞通道)、自由绘制(自选画布 + PNG 导入量化 + 封面模板)。

字体编辑器

14×14 三区网格(12×12 主区 + 左 2 入侵 + 下 2 尾部),预览条 + 试排,导出 AFNT v2。

音频工作站

三件套:音色(FC/FM/模拟三族)、pattern(横向钢琴卷帘 64 步)、music(8 轨 bpm+swing)。导出 .aud。

模拟器即调试器

同一程序:收起面板即纯运行器,展开即全功能调试器(断点/快照/回放/状态视图)。

魔塔编辑器

21 层魔塔关卡编辑:图块绘制 / 楼层管理 / 怪物数值 / 校验(楼梯·连通·钥匙收支),一键现场重打包 .aec 试玩。

3D FPS 地图编辑器

Doom 风格扇区编辑(顶点/线/扇区/物件),画多边形自动建区缝合,软件渲染 3D 第一人称漫游预览。

代码编辑器

按 T16 暂缓:代码用任意文本编辑器写 .ajs,打包自动收集,装带冒烟 + 调试器兜错。

工作流(代码编辑器暂缓期)

任意文本编辑器写 mygame/main.ajs(+ gfx/ audio/ …)
  → 图像编辑器产出 .til/.map/.bm2(封面 cover.bin 或 cover.png)
  → 音频工作站产出 audio/*.aud
  → 打包环境一键出品 mygame.aec(≤256KB 检查 + 冒烟)
  → 模拟器/调试器装载运行;主机 index.html 导入卡带即玩
